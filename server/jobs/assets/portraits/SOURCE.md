# Demo portrait fixtures

AI-generated portraits from [Personified](https://github.com/TheTechBasket/personified)
by All SVG Icons, downloaded November 22, 2026.

Source revision: `5a5e75043cff7cdc37e95d919ba0e618e7d4c27d`.
Original files: `img/256/<id>.webp`. The trimmed index retains the source IDs,
fixture age, and source presentation category for choosing adult demo portraits.
These categories describe fixture selection, not inferred user identities.

The included Free Asset License permits images within distributed applications
and clearly identified demo data. These images must stay demo fixtures; they
must not be presented as real dating profiles or offered as an asset library.
See [LICENSE.md](LICENSE.md) for the full downloaded license.

There are 219 distinct faces, reused across 500 fictional demo accounts.
The seed converts the bundled WebP images to JPEG for the existing photo API.
No network access is needed at seed time or while browsing profiles.
